📋 Investigator Desktop — Changelog

Investigator Desktop

Version 1.1.0 — Feature update

Desktop environment
Added a Windows XP-inspired desktop, Bliss wallpaper, desktop icons, movable windows, taskbar, Start menu, live clock, and window controls.
Documents
Added a Documents explorer with Research and Documentation folders. Research files are protected. Added the Not Canon documentation location and its disclaimer before opening.
Terminal
Added the Investigator Terminal with commands for help, clear, echo, date, time, whoami, dir, cd, ver, and exit.
User files — new
Create, open, edit, rename, and delete personal text files. Files are stored in this browser using local storage.
Minesweeper — new
Added Beginner, Intermediate, and Expert game modes, mine flags, a timer-free board, win/loss detection, and restart.
Paint — new
Added a drawing canvas with selectable colors, adjustable brush size, eraser, clear canvas, and image saving.
Changelog — new
Added this application to document public desktop features and updates.
Start menu
Added shortcuts for the desktop apps, Restart Desktop, and Return to Home.
Privacy and content
Protected research material and secret story content are intentionally not reproduced in this changelog.

The changelog describes public features of this desktop project. It does not disclose protected files or hidden story information.
