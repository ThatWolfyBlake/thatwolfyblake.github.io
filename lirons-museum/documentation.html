📋 Investigator Desktop — Changelog

Investigator Desktop

Version 1.3.0 — Desktop improvements

Desktop environment
Windows XP-inspired desktop, Bliss wallpaper, desktop icons, movable windows, taskbar, Start menu, live clock, and window controls.
Documents
Added a Documents explorer with Research and Documentation folders. Research files are protected. Added the Not Canon documentation location and its disclaimer before opening.
Terminal
Investigator Terminal with help, clear, echo, date, time, whoami, dir, cd, ver, exit, and execute commands.
User files
Create, open, edit, rename, and delete personal text files. Files are stored in this browser using local storage.
Minesweeper
Beginner, Intermediate, and Expert game modes, mine flags, win/loss detection, and restart.
Paint
Drawing canvas supports mouse and touch input, adjustable brush size, color selection, erasing, and image export.
Desktop personalization
Some desktop preferences and application shortcuts are remembered by this browser.

The changelog describes public features of this desktop project. It does not disclose protected files or hidden story information.
